# 動く絵合わせパズル

`index.html` をブラウザで開くだけで遊べます。ローカルサーバーを使う場合は、このフォルダで次を実行してください。

```powershell
python -m http.server 8000
```

その後、`http://localhost:8000` を開きます。

## 本番素材への差し替え

`assets` フォルダに次の名前で配置してください。どちらも横長 16:9 を推奨します。

- `sunset-crossing.png` — パズル用の静止画
- `sunset-crossing.mp4` — 完成後に自動再生する動画

静止画または動画が未配置でも、仮の夕焼けイラストと短いCSSアニメーションで動作確認できます。
